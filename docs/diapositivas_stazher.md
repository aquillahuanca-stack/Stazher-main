# Stazher: Sistema de gestión de asistencia para pasantes

## Diapositiva 1 - Introducción
- Proyecto: Stazher
- Objetivo: controlar asistencia y gestionar pasantes
- Tecnología: PHP + MySQL + Bootstrap
- Enfoque: mejora de procesos administrativos y de horas laboradas

---

## Diapositiva 2 - Problema identificado
- Registro manual de asistencia
- Duplicidad de información
- Pérdida de control de horarios
- Dificultad para generar reportes con rapidez

---

## Diapositiva 3 - Objetivos del sistema
- Registrar entrada y salida
- Mantener información de pasantes
- Organizar horarios por área y turno
- Generar reportes para administración

---

## Diapositiva 4 - Funcionalidades principales
- Inicio de sesión administrativo
- Gestión de pasantes
- Configuración de cursos, horarios y áreas
- Control de asistencia diaria
- Reportes y consulta de horas

---

## Diapositiva 5 - Usuarios del sistema
- Administrador: gestión completa
- Pasante: marcación de entrada/salida
- Personal de RRHH: revisión y consultas

---

## Diapositiva 6 - Flujo de uso
1. El pasante ingresa su código
2. El sistema valida el registro del día
3. Se registra entrada o salida
4. Se calculan horas y estados de asistencia
5. El administrador revisa reportes y consolidado

---

## Diapositiva 7 - Arquitectura técnica
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Base de datos: MySQL
- Generación de reportes: TCPDF
- Servidor recomendado: XAMPP

---

## Diapositiva 8 - Beneficios
- Reducción de errores manuales
- Mejora en la trazabilidad de datos
- Ahorro de tiempo administrativo
- Mejor control operativo de pasantes

---

## Diapositiva 9 - Verificación realizada
- Se validaron sintaxis de archivos principales con PHP
- Resultado: sin errores de sintaxis en `attendance.php`, `admin/home.php` y `admin/index.php`
- Se constató que la base del sistema está operativa a nivel de carga principal

---

## Diapositiva 10 - Conclusión
Stazher es una solución útil, práctica y funcional para la administración de asistencia de pasantes. Su implementación mejora la eficiencia, control y transparencia del proceso de personal en prácticas.

---

## Diapositiva 11 - Recomendaciones finales

- Asegurar el entorno con HTTPS
